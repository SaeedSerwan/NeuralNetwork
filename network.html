From neurons to a network.

One neuron answers one small question. Put neurons side by side and you get a layer; stack layers and you get a network that can read handwritten digits. This chapter builds that network and counts every knob in it.

So far

One neuron: inputs × weights, plus a bias, squished by σ (chapter 2).

In this chapter

Neurons arranged in layers, why layers might help, how many weights and biases that needs, a whole layer written as one matrix multiplication, why the squish matters, and a live forward pass.

01The network: 784 → 16 → 16 → 10

In chapter 2 one neuron took a few inputs and produced one number. A single neuron can only answer one simple question. To read a digit we need many neurons, working in layers.

Our network has four layers. The 784 pixel neurons come first. The last layer has 10 neurons, one per digit: the brightest one is the answer. In between are two hidden layers of 16 neurons each. Sixteen is an arbitrary choice; you will try other sizes in the playground. The activations of one layer decide the activations of the next.

At the end of this chapter you will draw a digit and watch this network read it, with every activation lighting up.

02Why layers? The hope

Why put layers in the middle at all? The hope is that each layer builds slightly bigger pieces out of the layer below. A 9 is a loop up top and a line on the right; an 8 is two loops. So maybe one neuron in the last hidden layer lights up for “loop up top”, another for “line on the right”. And a loop is built from small edges, so maybe the layer before finds edges.

Edges → parts → digits

Hover a digit to see the parts it needs, or a part to see its edges.

The same idea works for speech: sounds → syllables → words → sentences. Whether the network really learns tidy pieces like these is a different question: you will check what it actually learned in chapter 6.

03Count the knobs

Every weight and every bias is a knob you can turn. A layer of 16 neurons that reads 784 inputs needs 784 × 16 weights and 16 biases. Learning means turning all of these knobs until the network reads digits correctly. Imagine setting 13,002 of them by hand: that is why we let the computer do it.

04The compact way: one layer = one matrix multiply

Writing 784 products for each of 16 neurons is long. Put the activations of a layer in a column \(a^{(0)}\), and the weights in a matrix W whose row k holds the weights of neuron k. Then one multiplication computes every weighted sum at once:

\[ a^{(1)} = \sigma\big(W a^{(0)} + b\big) \]

A small layer: 4 inputs, 3 neurons

Hover a neuron on the right to see the row and the column it uses.

Libraries such as PyTorch and NumPy are built for exactly this operation, and GPUs compute it extremely fast. That is a big reason why deep learning became practical.

05Follow the sizes: the forward pass in code

The matrix form above is exactly how the network is written in code. Real code also pushes many pictures through at once, a batch of B images, so every array gets an extra dimension of size B.

Each layer is one line of NumPy: multiply the activations by the transposed weight matrix, add the bias, squish. Watch how the shape of the data changes from layer to layer: 784 numbers per picture shrink to 16, then 16, then 10 scores. The middle dimension of a multiplication must match, and it disappears.

Array shapes through the network

Change the layer sizes or the batch size, then press ▶ Play. Blocks are drawn to a log scale so that 784 and 10 both fit.

batch B
Watch for: in A @ W.T the inner sizes must be equal (784 and 784); the result keeps the outer sizes (B and 16). The bias has one number per neuron and is added to every row of the batch (“broadcasting”).

06Sigmoid or ReLU, and why not nothing?

The sigmoid was the early choice, inspired by real neurons being on or off; it is still good at the output when we want a probability. Inside modern networks the default is ReLU, \(\mathrm{ReLU}(z) = \max(0, z)\), because deep networks train much more easily with it. But why use any activation at all?

A 1 → 8 → 8 → 1 network tries to fit a curve

Pick a target and an activation, then train. Without an activation the network can only draw a straight line.

Key idea: without an activation function, stacked layers collapse into one linear model: straight lines on straight lines are still straight.
