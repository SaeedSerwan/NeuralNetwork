One neuron: multiply, add, squish.

Everything in a neural network is built from one tiny unit. In this chapter you take it apart: what it holds, what it computes, and the three ingredients that decide its answer: weights, a bias and an activation function.

So far

A real neuron collects signals through connections of different strengths and fires above a threshold (chapter 1).

In this chapter

The artificial version of exactly that: a weighted sum, a bias and a squishing function, first on a four-word spam detector, then on a 784-pixel picture.

01A neuron is a thing that holds a number

In chapter 1 we decided to copy the brain. Its basic unit is the neuron, so we start with one.

For now, think of a neuron as a box that holds one number between 0 and 1, called its activation. A 28 × 28 picture of a digit has 784 pixels, so we use 784 neurons: 0 for a black pixel, 1 for a white one, grey in between. These 784 neurons are the input layer of the network.

Key idea: the picture is just a list of 784 numbers. Everything the network does is arithmetic on that list.

02One neuron: a weighted sum of the layer before

Each connection between two neurons has a weight, a number. Positive weights are drawn green, negative ones red. To compute one neuron of the next layer, multiply each pixel by its weight and add all 784 products: a weighted sum.

\[ a = \sigma\big(w_1 a_1 + w_2 a_2 + \dots + w_n a_n + b\big) \]

One neuron, step by step

A spam detector with four inputs: 1 if the word is in the email, 0 if not. Click words to change the email, then press ▶ Play.

Watch for: words that are absent send nothing (their input is 0, so input × weight = 0). Red weights push the sum down. The bias shifts the sum before the squish.

The same happens with pictures, just with 784 inputs instead of four. The neuron below was set by hand to look for a horizontal stroke: green weights across the middle, red weights above and below. Its sum is large only when the middle is bright and the rows above and below are dark. Try other digits and other weight patterns.

The same idea in the general form you will meet in books: inputs \(x_i\), weights \(w_i\), a bias \(w_0\) and an activation function \(g\).

\[ \hat y = g\Big(w_0 + \sum_{i=1}^{m} x_i w_i\Big) \]

Key idea: the weights say which pixel pattern the neuron looks for. Here they were chosen by hand; in chapters 4–6 the network finds them itself.

03Squish it into 0 … 1: the sigmoid

The weighted sum can be any number, −37 or 512. But an activation should be between 0 and 1. So we pass the sum through a squishing function, the sigmoid σ: very negative numbers become close to 0, very positive ones close to 1, and around 0 it rises steadily.

\[ \sigma(z) = \frac{1}{1 + e^{-z}} \]

Activation functions

Move z. The dashed curve is the slope, which matters in chapters 4, 5 and 10.

The slope of the sigmoid is never more than 0.25, at z = 0. Remember this number: in chapter 10 it explains why deep sigmoid networks stop learning.

04The bias: how high before it lights up?

With the sigmoid alone, a neuron is “half on” as soon as its weighted sum is above 0. Maybe it should only fire when the sum is above 10, so that a few stray bright pixels do not count. Then add a bias b = −10 before squishing.
