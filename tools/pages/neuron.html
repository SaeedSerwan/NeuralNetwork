What is inside a neural network?

A neural network is not magic. It is a long list of numbers and three operations: multiply, add, squish. On this page you build one neuron, then a layer, then the 784 → 16 → 16 → 10 network that reads handwritten digits, and you count every knob it has.

01A neuron is a thing that holds a number

For now, think of a neuron as a box that holds one number between 0 and 1, called its activation. A 28 × 28 picture of a digit has 784 pixels, so we use 784 neurons: 0 for a black pixel, 1 for a white one, grey in between. These 784 neurons are the input layer of the network.

Key idea: the picture is just a list of 784 numbers. Everything the network does is arithmetic on that list.

02The network: 784 → 16 → 16 → 10

Our network has four layers. The 784 pixel neurons come first. The last layer has 10 neurons, one per digit: the brightest one is the answer. In between are two hidden layers of 16 neurons each. Sixteen is an arbitrary choice; you will try other sizes in the playground. The activations of one layer decide the activations of the next.

03Why layers? The hope

Why put layers in the middle at all? The hope is that each layer builds slightly bigger pieces out of the layer below. A 9 is a loop up top and a line on the right; an 8 is two loops. So maybe one neuron in the last hidden layer lights up for “loop up top”, another for “line on the right”. And a loop is built from small edges, so maybe the layer before finds edges.

Edges → parts → digits

Hover a digit to see the parts it needs, or a part to see its edges.

The same idea works for speech: sounds → syllables → words → sentences. Whether the network really learns tidy pieces like these is a different question: see what it actually learned.

04One neuron: a weighted sum of the layer before

Each connection between two neurons has a weight, a number. Positive weights are drawn green, negative ones red. To compute one neuron of the next layer, multiply each pixel by its weight and add all 784 products: a weighted sum.

\[ a = \sigma\big(w_1 a_1 + w_2 a_2 + \dots + w_n a_n + b\big) \]

One neuron, step by step

A spam detector with four inputs: 1 if the word is in the email, 0 if not. Click words to change the email, then press ▶ Play.

Watch for: words that are absent send nothing (their input is 0, so input × weight = 0). Red weights push the sum down. The bias shifts the sum before the squish.

The same happens with pictures, just with 784 inputs instead of four. The neuron below was set by hand to look for a horizontal stroke: green weights across the middle, red weights above and below. Its sum is large only when the middle is bright and the rows above and below are dark. Try other digits and other weight patterns.

The same idea in the general form you will meet in books: inputs \(x_i\), weights \(w_i\), a bias \(w_0\) and an activation function \(g\).

\[ \hat y = g\Big(w_0 + \sum_{i=1}^{m} x_i w_i\Big) \]

Key idea: the weights say which pixel pattern the neuron looks for. Here they were chosen by hand; in Part 2 the network finds them itself.

05Squish it into 0 … 1: the sigmoid

The weighted sum can be any number, −37 or 512. But an activation should be between 0 and 1. So we pass the sum through a squishing function, the sigmoid σ: very negative numbers become close to 0, very positive ones close to 1, and around 0 it rises steadily.

\[ \sigma(z) = \frac{1}{1 + e^{-z}} \]

Activation functions

Move z. The dashed curve is the slope, which matters in Part 2 and Part 4.

The slope of the sigmoid is never more than 0.25, at z = 0. Remember this number: in Part 4 it explains why deep sigmoid networks stop learning.

06The bias: how high before it lights up?

With the sigmoid alone, a neuron is “half on” as soon as its weighted sum is above 0. Maybe it should only fire when the sum is above 10, so that a few stray bright pixels do not count. Then add a bias b = −10 before squishing.

07Count the knobs

Every weight and every bias is a knob you can turn. A layer of 16 neurons that reads 784 inputs needs 784 × 16 weights and 16 biases. Learning means turning all of these knobs until the network reads digits correctly. Imagine setting 13,002 of them by hand: that is why we let the computer do it.

08The compact way: one layer = one matrix multiply

Writing 784 products for each of 16 neurons is long. Put the activations of a layer in a column \(a^{(0)}\), and the weights in a matrix W whose row k holds the weights of neuron k. Then one multiplication computes every weighted sum at once:

\[ a^{(1)} = \sigma\big(W a^{(0)} + b\big) \]

A small layer: 4 inputs, 3 neurons

Hover a neuron on the right to see the row and the column it uses.

Libraries such as PyTorch and NumPy are built for exactly this operation, and GPUs compute it extremely fast. That is a big reason why deep learning became practical.

09Sigmoid or ReLU, and why not nothing?

The sigmoid was the early choice, inspired by real neurons being on or off; it is still good at the output when we want a probability. Inside modern networks the default is ReLU, \(\mathrm{ReLU}(z) = \max(0, z)\), because deep networks train much more easily with it. But why use any activation at all?

A 1 → 8 → 8 → 1 network tries to fit a curve

Pick a target and an activation, then train. Without an activation the network can only draw a straight line.

Key idea: without an activation function, stacked layers collapse into one linear model: straight lines on straight lines are still straight.
